# 质量监督交付约束

运行复盘提供「运行记录 / 质量监督」页签。后台首次登记全部业务任务，后续增量审查；数据库保存任务台账、消息覆盖范围、审查批次及问题处理历史。采用现有调度器和 Agent Runtime，不建立用户自动化，不依赖临时工作目录。

## 模型选择必须先有实测

- 优先 CodeBuddy；每家厂商只选择一个代表模型，覆盖不同积分消耗水平，模型ID和可调用性以当前账号实测为准。
- Codex `gpt-6.1-sol` 是同题基准。CodeBuddy 内的同名模型单独列出，以识别运行时差异。
- 首轮采用冻结、答案独立的监督评测集，覆盖真实问题、无问题反例、授权、最新决定、跨模块映射、误报、覆盖缺失、长轨迹和增量读取。重复运行并保存全部原始调用及结果。
- 入围模型继续进行实际工具使用、补读、跨轮审查、结构化提交及 int 真实监督任务测试。材料判断成绩不代替端到端验收。
- 质量优先：分别报告关键问题召回、误报、证据有效性、结论边界、重复稳定性、运行失败率；另报告耗时、token和实际返回积分。不把美元0当免费，不编造未返回的价格。
- 报告排名是本评测集的表现，不是通用模型能力结论。按独立案例分析差异，重复采样不冒充新增独立样本。
- CodeBuddy 无法达到基准质量时保留 Codex 6.1-sol；不因费用较低自动降低监督质量。最终候选需通过完整联调后才作为默认推荐。

## 自动范围与完成轮次

自动监督只审查已完成任务的完成快照，不再持续追踪开发中的任务：

- 任务进入 done 类别时建立一轮（`supervision_round`），截止时间取建立时刻；本轮材料只包含截止时间之前登记的执行与交付记录。完成之后的普通评论、扫描、服务重启都不会创建新的自动批次。
- 轮次身份由 `(workspace_id, issue_id, sequence)` 与"同一任务只有一个开放轮次"两个唯一索引确定，重复状态请求和并发扫描只会命中同一行。
- 重新打开任务时关闭开放轮次，排队中的批次取消，运行中的批次在提交时归档结果且不更新当前结论、问题清单和阅读进度；再次完成建立新轮次，已完整覆盖且未变化的材料复用覆盖证据，只补审新增或变化材料。
- 手动监督可以对未完成任务发起（`force_review`），派发记为 `manual` 范围，不建立轮次，也不恢复持续追踪；工作区级"检查新增内容"只安排已完成任务。
- 升级时扫描器为已完成任务幂等补建轮次（截止时间取首次登记时刻），已有覆盖不会全量重跑，未覆盖材料接续处理。
- 轮次与批次归属只新增表 `supervision_round`、`supervision_batch_round` 及并发索引，不修改既有监督表结构；旧程序读取忽略新表，回退不需要撤销数据。

## 交付门禁

用户以 `/note` 开头的评论是给监督者的备注，必须纳入变更接收、首次全量和增量材料；详情标识「用户监督备注」。备注用于定位用户关切，不能单凭主观反馈判定缺陷，不自动转换为给原负责人的修改指令或触发任务。评测覆盖漏读备注、错误派发、依据实际产物确认缺陷以及核验后无缺陷的反例。

全量/增量、审查中变更、迟到消息、大结果补读、重启恢复、重复回调、权限和问题闭环均须验收。授权包括本功能提交及 int 验收后主分支推送。用户最新决定：最终生产发布前必须取得用户明确确认；int 验收通过不自动提交生产发布请求。先交付模型榜单、联调结果、候选提交、产物身份及剩余问题，再等待生产发布确认。失败不发布，生产失败恢复旧程序。默认监督配置关闭，用户选择 Agent 后启用。


## 主动只读调查与第二轮评测

监督设置提供主动调查开关，已有配置缺省关闭。运行使用专用 MCP 读取当前任务历史、关联目录和仓库，只开放分页文本读取、搜索和限定 Git 查询。工具证据保存到当前审查批次，问题和解决记录可引用；初始材料覆盖与调查证据分别校验。当前工作目录内容不代表旧运行的源码。调查运行不能访问通用 Shell、写文件、执行测试、浏览器或发布。

CodeBuddy 监督进程关闭延迟工具加载，使专用 MCP 直接可调用；禁用自动记忆及用户项目设置加载，不修改普通 Agent 配置。调查日志复用运行轨迹，详情展示最近读取、失败和未读范围。批次停止、配置关闭、负责人权限变化及预算耗尽后拒绝新的调查证据。

第二轮只比较 CodeBuddy 的 GPT 6.1 sol、HY4、GLM 5.3、DeepSeek 4.1 Flash、Kimi K3。目标是120个单阶段案例、20条四阶段故事、40个主动调查案例，各模型三次采样，以及每模型8个联调场景。真实纠正候选须核对原始工具证据；历史副本、同任务变体及重复采样不计成新增独立任务。正式题集冻结前先做12题试运行，失败与修正记录保留。真实案例不足时报告缺口。

通俗报告交付到 `/data/ida/docs/quality-supervision-evaluation/`。正式原始记录保存在源码目录之外。材料判断与主动调查分别报告漏报、误报、幻觉、证据支持、恢复能力、协议有效性和成本；原生Codex与Opus不重测，旧分数不混入本轮结果。生产更新仍需用户最终确认。

# 知识库 Web 整理与网页导入（开发验收）

本阶段在 `feature/dsh-knowledge-curation` 独立开发，生产尚未发布。

## 用户入口

知识库页面展示资源目录和搜索结果。工作区 owner/admin 可确认删除文件或整个文件夹；
删除请求成功后刷新目录与搜索。工作区根目录不能删除，普通成员没有删除入口，服务端
也校验删除权限及完整工作区路径。

页面可提交 HTTP/HTTPS 地址。下载、索引、完成和失败状态保存到 `knowledge_import`；
刷新或服务重启后可查询最近20次导入。网络结果不确定时重试同一请求编号，服务端返回
已有任务；同一编号更换 URL 返回409。下载阶段中断的记录在两分钟后明确失败，提示先
检查资源列表，避免上游已提交但本地未确认时重复导入。索引完成后刷新目录和搜索。

## 下载边界

- 下载器只连接已经校验并固定的公网 IP，不继承宿主 HTTP 代理。
- 每次连接核对 DNS 全部结果，混合公网/私网结果拒绝；逐跳校验重定向，最多5跳。
- 拒绝本机、私网、链路本地、云元数据、共享地址、保留地址及地址转换绕行。
- 下载总超时30秒、响应头10秒、响应体最多10 MiB；支持 HTML、文本、Markdown、PDF。
- 服务端先下载字节并上传临时文件给 OpenViking，再提交索引，不把用户 URL 交给上游抓取。
- 返回通用下载错误，日志和错误不回显带签名参数的 URL。前端响应异常日志隐藏原始载荷。

## 数据与兼容

迁移678建表无外键；679和680分别单语句并发创建唯一索引与工作区排序索引，登记
中断重试清理钩子。工作区删除显式清理导入记录，验收种子规则清空导入任务。
列表的 `format=json` 返回结构化目录，默认输出继续供现有 CLI 消费。
新增前端 API 使用 zod 与 `parseWithFallback`，错误响应不会显示成导入成功。

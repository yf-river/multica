## 开发模型

本地开发使用一个共享 PostgreSQL 容器，每个 checkout 或 worktree 使用独立数据库。

- 主仓库通常使用 `.env` 和 `POSTGRES_DB=multica`。
- 每个 worktree 使用自己的 `.env.worktree`。
- 后端和前端端口按 worktree 分配，避免互相冲突。

## 依赖

- Node.js `v20+`
- `pnpm` `v10.28+`
- Go `v1.26+`
- Docker

## 主仓库

```bash
cp .env.example .env
make setup-main
make start-main
```

日常命令：

```bash
make start-main
make stop-main
make check-main
```

## Worktree

```bash
git worktree add ../multica-feature -b feat/my-change main
cd ../multica-feature
make worktree-env
make setup-worktree
make start-worktree
```

日常命令：

```bash
make start-worktree
make stop-worktree
make check-worktree
```

## 常用检查

```bash
pnpm --filter @multica/web typecheck
pnpm --filter @multica/web build
pnpm --filter @multica/core test
pnpm exec playwright test

cd server
go test ./...
go run ./cmd/migrate up
```

修改 SQL 查询后运行：

```bash
cd server
sqlc generate
```

## 测试要求

涉及 shared API、handler、migration、训练评估、小队、运行时或可观测能力时，至少补对应层级的聚焦测试。生产验收相关改动还应跑：

```bash
pnpm acceptance:verify
```

## 数据库

查看当前 checkout 使用的数据库：

```bash
cat .env
cat .env.worktree
```

重置当前 checkout 数据库：

```bash
make stop
make db-reset
make start
```

`make db-reset` 会拒绝远程数据库，避免误删共享环境。

## 安装方式

### Homebrew

```bash
brew install multica-ai/tap/multica
```

### 从源码构建

```bash
git clone https://github.com/multica-ai/multica.git
cd multica
make build
cp server/bin/multica /usr/local/bin/multica
```

### 从 Release 下载

```bash
OS=$(uname -s | tr '[:upper:]' '[:lower:]')
ARCH=$(uname -m)
if [ "$ARCH" = "x86_64" ]; then ARCH="amd64"; fi

LATEST=$(curl -sI https://github.com/multica-ai/multica/releases/latest \
  | grep -i '^location:' | sed 's/.*tag\///' | tr -d '\r\n')

curl -sL "https://github.com/multica-ai/multica/releases/download/${LATEST}/multica_${OS}_${ARCH}.tar.gz" \
  -o /tmp/multica.tar.gz
tar -xzf /tmp/multica.tar.gz -C /tmp multica
sudo mv /tmp/multica /usr/local/bin/multica
rm /tmp/multica.tar.gz
```

### Windows

```powershell
irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
```

## 连接团队内部服务

本机开发或默认自部署环境：

```bash
multica setup self-host
```

自定义域名：

```bash
multica setup self-host --server-url https://api.example.internal --app-url https://multica.example.internal
```

`setup self-host` 会写入 CLI 配置、打开浏览器登录、发现工作区，并启动 daemon。

## 验证

```bash
multica daemon status
```

确认：

1. daemon 状态是 `running`。
2. 至少识别到一个 Agent CLI。
3. 至少监听一个工作区。

如果 Agent 列表为空，先安装团队需要的 CLI，例如 `codex`、`claude`、`opencode`、`openclaw`、`kimi`、`kiro-cli`，然后重启：

```bash
multica daemon stop && multica daemon start
```

## 更新

```bash
brew upgrade multica-ai/tap/multica
```

手动或脚本安装可使用：

```bash
multica update
```

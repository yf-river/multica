`multica` CLI 用来连接团队内部 Multica 服务、完成登录、管理工作区，并启动本机 daemon 执行 Agent 任务。

## 认证

```bash
multica login
```

打开浏览器完成账号密码登录，生成本机 token，并自动发现可访问工作区。

```bash
multica login --token <mul_...>
```

用于无头环境或自动化环境。为了避免 token 进入 shell history，可以使用 `--token=` 进入交互输入。

```bash
multica auth status
multica auth logout
```

分别用于查看当前登录状态和退出登录。

## 连接自部署环境

```bash
multica setup self-host
multica setup self-host --server-url https://api.example.internal --app-url https://multica.example.internal
```

如果浏览器和 CLI 不在同一台机器上，使用 `--callback-host` 指定浏览器可访问的回调地址。

## Daemon

```bash
multica daemon start
multica daemon start --foreground
multica daemon stop
multica daemon status
multica daemon status --output json
```

daemon 会检测本机 Agent CLI，注册运行时，轮询任务队列，并把输出、失败原因、usage 和 trace 写回服务端。

日志：

```bash
multica daemon logs
multica daemon logs -f
multica daemon logs -n 100
```

## 工作区

```bash
multica workspace list
multica workspace watch <workspace-id>
multica workspace unwatch <workspace-id>
multica workspace get <workspace-id>
multica workspace member list <workspace-id>
```

被监听的工作区会用 `*` 标记。daemon 只处理已监听工作区中的任务。

更新工作区需要 admin 或 owner 权限：

```bash
multica workspace update <workspace-id> --name "AI Studio"
multica workspace update <workspace-id> --description "团队内部 Multica 工作区" --issue-prefix AI
```

长文本可走 stdin：

```bash
cat <<'CTX' | multica workspace update <workspace-id> --context-stdin
我们是一支 AI-native 团队，使用 Multica 管理 issue、小队、Agent 执行和训练评估。
CTX
```

## Issue

```bash
multica issue list
multica issue list --status in_progress
multica issue list --priority urgent
multica issue get MUL-123
multica issue get <uuid> --output json
```

默认表格输出会显示可复制的 issue key。需要完整 UUID 时使用 `--full-id`。

## 常用配置

```bash
multica config set app_url https://multica.example.internal
multica config set server_url wss://api.example.internal/ws
multica config get
```

多环境可以使用 profile：

```bash
multica setup self-host --profile staging --server-url https://api-staging.example.internal --app-url https://staging.example.internal
multica daemon start --profile staging
```

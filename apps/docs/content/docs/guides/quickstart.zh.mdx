---
title: 快速开始
description: 在团队内部 Multica 中连接运行时并分派第一个 Agent 任务。
---

## 1. 连接你的运行时

团队内部部署或本机开发环境使用：

```bash
multica setup self-host
```

如果前后端部署在自定义域名：

```bash
multica setup self-host --server-url https://api.example.internal --app-url https://multica.example.internal
```

该命令会写入 CLI 配置、打开浏览器登录、发现可访问工作区，并启动本机 daemon。

## 2. 检查运行时在线

进入 **设置 → 运行时**，确认你的电脑在线，并且识别到了可用 Agent CLI。没有可用 Agent 时，先安装 `codex`、`claude`、`opencode`、`openclaw`、`kimi` 或团队指定的 CodeBuddy/runtime。

## 3. 创建 Agent

进入 **设置 → Agent**，选择运行时、provider 和模型。Agent 的名称会出现在 issue 分派、小队执行、评论和运行历史中。

## 4. 分派第一个 issue

在看板创建 issue，并把 assignee 设为 Agent 或小队。daemon 会领取任务、创建隔离工作目录、启动 Agent CLI，并把状态、输出、失败原因、usage 和 trace 写回 Multica。

## 5. 验证证据

任务结束后检查：

- issue 时间线和评论。
- **训练与评估 → 运行历史**。
- task usage、trace 事件、耗时、模型和失败原因。
- 小队 SOP run 及每一步事件。

---
title: 登录与注册配置
description: 配置账号密码登录、注册控制和工作区创建控制。
---

Multica 使用账号密码登录。注册开启时，某个账号第一次成功登录会创建账号；之后登录必须使用同一个密码。

## 注册控制

| 变量 | 用途 |
| --- | --- |
| `ALLOW_SIGNUP` | 设为 `false` 后禁止创建新账号。已有用户仍可登录。 |
| `ALLOWED_ACCOUNTS` | 可选，逗号分隔的账号名白名单。非空时，只有列表中的账号可以被创建。 |
| `DISABLE_WORKSPACE_CREATION` | 设为 `true` 后所有人调用 `POST /api/workspaces` 都返回 403。用户只能加入被邀请的工作区。 |

修改后重启 backend 生效。Web UI 会从 `/api/config` 读取
`ALLOW_SIGNUP` 和 `DISABLE_WORKSPACE_CREATION`，不需要重新构建 web。

## 私有部署推荐顺序

1. 先用 `ALLOW_SIGNUP=true`、`DISABLE_WORKSPACE_CREATION=false` 启动。
2. 用管理员账号登录并创建共享工作区。
3. 设置 `DISABLE_WORKSPACE_CREATION=true`。
4. 如需限制成员范围，再设置 `ALLOWED_ACCOUNTS`。
5. 重启 backend。

如果 `ALLOW_SIGNUP=false`，还没有账号的受邀用户也无法接受邀请，因为他们无法创建用于登录的账号。

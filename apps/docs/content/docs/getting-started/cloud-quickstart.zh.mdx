---
title: 内部部署快速开始
description: 面向团队内部 Multica 环境的最短接入路径。
---

Multica 当前按团队内部系统使用。推荐先接入已经部署好的团队环境，再让个人电脑或服务器作为运行时加入工作区。

## 1. 登录团队环境

向管理员确认前端地址、账号和初始密码。登录后进入你的工作区，优先检查：

- **训练与评估**：查看提示词、数据集、测试套件、实验和运行历史。
- **小队**：查看 user-center 小队、Multica 编码小队等内部协作模板。
- **运行时**：确认可执行 Agent 任务的电脑是否在线。

## 2. 安装 CLI 并连接运行时

把下面这段交给你正在使用的 AI 编码工具，或手动执行等价步骤：

```text
阅读仓库 CLI_INSTALL.md，安装 Multica CLI，连接团队内部 Multica 服务，登录并启动 daemon。
```

手动安装：

```bash
brew install multica-ai/tap/multica
```

没有 Homebrew 时：

```bash
curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
```

Windows：

```powershell
irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
```

连接内部服务：

```bash
multica setup self-host --server-url https://api.example.internal --app-url https://multica.example.internal
```

本机开发环境可以直接使用：

```bash
multica setup self-host
```

## 3. 验证运行时

打开 **设置 → 运行时**，确认你的电脑显示为在线。运行时会报告可用的 Agent CLI，例如 `codex`、`claude`、`opencode`、`openclaw`、`kimi`、`kiro-cli`。

## 4. 创建或选择 Agent

打开 **设置 → Agent**，选择刚连接的运行时和可用模型。团队演示环境默认关注本机 Codex runtime，轻量验收优先使用 `gpt-5.3-codex-spark`，额度不足时切到 `gpt-5.4-mini`。

## 5. 分派第一个任务

在 issue 看板创建任务，分派给 Agent 或小队。完成后在 issue、运行历史、trace、usage 和训练评估报告中核对结果。

---

Multica는 계정 이름과 비밀번호로 로그인합니다. 회원가입이 활성화되어 있으면 특정 계정의 첫 성공 로그인 때 계정이 생성됩니다. 이후에는 같은 비밀번호가 필요합니다.

## 회원가입 제어

| 변수 | 목적 |
| --- | --- |
| `ALLOW_SIGNUP` | `false`로 설정하면 새 계정 생성을 차단합니다. 기존 사용자는 계속 로그인할 수 있습니다. |
| `ALLOWED_ACCOUNTS` | 선택 사항. 쉼표로 구분한 정확한 계정 이름 허용 목록입니다. 비어 있지 않으면 목록에 있는 계정만 생성할 수 있습니다. |
| `DISABLE_WORKSPACE_CREATION` | `true`로 설정하면 모든 `POST /api/workspaces` 호출이 403을 반환합니다. 사용자는 초대받은 워크스페이스에만 참여할 수 있습니다. |

변경 사항은 backend 재시작 후 적용됩니다. Web UI는 `/api/config`에서
`ALLOW_SIGNUP`과 `DISABLE_WORKSPACE_CREATION`을 읽으므로 web 재빌드는 필요하지 않습니다.

## 비공개 배포 권장 순서

1. `ALLOW_SIGNUP=true`, `DISABLE_WORKSPACE_CREATION=false`로 시작합니다.
2. 관리자 계정으로 로그인하고 공유 워크스페이스를 만듭니다.
3. `DISABLE_WORKSPACE_CREATION=true`를 설정합니다.
4. 필요한 경우 `ALLOWED_ACCOUNTS`를 설정합니다.
5. backend를 재시작합니다.

`ALLOW_SIGNUP=false`이면 아직 계정이 없는 초대 사용자는 로그인에 필요한 계정을 만들 수 없으므로 초대를 수락할 수 없습니다.
